# TOPIK 시리즈 영상 (한국어 · English · 日本語 · 中文)

한글 아래에 번역을 넣은 약 1분짜리 학습 영상. 강의 내용(데이터)만 바꾸면 3개 언어 영상이 자동으로 나옵니다.

## 1급 (TOPIK I) — 10강

| 강 | 주제 | 핵심 표현 |
|---|---|---|
| 1 | 한글 읽기 | 모음 · 자음 · 글자 조립 (가, 나라) |
| 2 | 인사 | 안녕하세요 / 감사합니다 / 저는 학생입니다 |
| 3 | 숫자 1 (한자어) | 일 이 삼 … 십 · 삼 번입니다 |
| 4 | 숫자 2 (고유어) | 하나 둘 셋 … · 사과 세 개 |
| 5 | 이것/저것 | 이것은 무엇입니까? · 저것은 가방입니다 |
| 6 | 나라와 직업 | 한국 사람입니다 · 저는 선생님입니다 |
| 7 | 장소 | 학교에 있어요 · 어디에 있어요? |
| 8 | 시간 | 지금 몇 시예요? · 두 시 삼십 분입니다 |
| 9 | 주문하기 | 물 주세요 · 얼마예요? · 커피 한 잔 주세요 |
| 10 | 1급 복습 | 퀴즈 5문항 |

요일(월화수목금)은 10강 안에 맞추려고 **2급으로 이동**했습니다 (`engine/lessons.py`의 `BACKLOG_LEVEL2`).
2급 이후도 같은 틀로 이어갑니다 (3~4급은 1.5~2분, 5~6급은 2~3분 예정).

## 한 강의 구성 (약 1분)
인트로 → 표현 2개(한글 읽기 + 뜻 + 소리 변화 + 따라 말하기) → 문장 만들기(카드 3장) → 퀴즈 → 마무리·다음 강 예고

## 폴더
```
topik/
  engine/lessons.py   강의 데이터 (여기만 고치면 됨)
  engine/build.py     음성(TTS) + 타임라인 생성
  engine/lesson.html  화면 틀 (장면 자동 생성)
  engine/render.cjs   프레임 렌더링 (Playwright)
  engine/make.sh      ./make.sh 3 4  → 영상 생성
  videos/             완성 영상  TOPIK1_L<번호>_<주제>_<en|ja|zh>.mp4
```
글꼴(`engine/fonts/`)과 중간 파일(`out/`)은 커밋하지 않습니다. 글꼴은 Noto Sans KR/JP/SC를 내려받아 넣으세요.

## 알려진 한계
- 음성은 구글 TTS입니다(로봇 느낌, 일본어·중국어는 약간 빠르게 조정). 공개용이면 유료 음성/성우로 교체 권장.
- 어휘·문법은 일반적인 1급 수준 기준 초안입니다. 공식 목록과 대조하고, 한·영·일·중 문구는 원어민 검수를 받으세요.
- 공식 TOPIK 기출문제는 쓰지 않았습니다(퀴즈는 새로 작성).
