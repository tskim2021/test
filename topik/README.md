# TOPIK 시리즈 영상 (6개 언어)

한글 아래에 번역을 넣은 약 1분짜리 학습 영상. 강의 내용(데이터)만 바꾸면 6개 언어 영상이 자동으로 나옵니다.

## 1급 (TOPIK I) — 20강 × 6개 언어

| 강 | 주제 | 강 | 주제 |
|---|---|---|---|
| 1 | 한글 읽기 | 11 | 요일 |
| 2 | 인사 | 12 | 날짜 |
| 3 | 숫자 1 (한자어) | 13 | 가족 |
| 4 | 숫자 2 (고유어) | 14 | 음식 |
| 5 | 이것/저것 | 15 | 일상 |
| 6 | 나라와 직업 | 16 | 과거형 |
| 7 | 장소 | 17 | 쇼핑 |
| 8 | 시간 | 18 | 교통 |
| 9 | 주문하기 | 19 | 사과와 부탁 |
| 10 | 중간 복습 | 20 | 1급 종합 복습 |

언어: English · 日本語 · 中文(简体) · ไทย · Bahasa Melayu · 中文(繁體·台灣). 2급 이후도 20강씩 같은 틀로 이어갑니다.

## 한 강의 구성 (약 1분)
인트로 → 표현 2개(한글 읽기 + 뜻 + 소리 변화 + 따라 말하기) → 문장 만들기(카드 3장) → 퀴즈 → 마무리·다음 강 예고

## 폴더
```
topik/
  engine/lessons.py   강의 데이터 (여기만 고치면 됨)
  engine/build.py     음성(TTS) + 타임라인 생성
  engine/lesson.html  화면 틀 (장면 자동 생성)
  engine/render.cjs   프레임 렌더링 (Playwright)
  engine/make.sh      [LANGS="th ms tw"] ./make.sh 3 4  → 영상 생성
  videos/             완성 영상  TOPIK1_L<번호>_<주제>_<en|ja|zh|th|ms|tw>.mp4 (git에는 올리지 않음, 로컬 생성)
```
글꼴(`engine/fonts/`)과 중간 파일(`out/`)은 커밋하지 않습니다. 글꼴은 Noto Sans KR/JP/SC/Thai/TC를 내려받아 넣으세요.

## 알려진 한계
- 음성은 구글 TTS입니다(로봇 느낌, 일본어·중국어는 약간 빠르게 조정). 공개용이면 유료 음성/성우로 교체 권장.
- 어휘·문법은 일반적인 1급 수준 기준 초안입니다. 공식 목록과 대조하고, 한·영·일·중 문구는 원어민 검수를 받으세요.
- 공식 TOPIK 기출문제는 쓰지 않았습니다(퀴즈는 새로 작성).
- 태국어·말레이어는 `engine/i18n.py`의 직접 작성 번역표, 대만 중국어는 간체를 OpenCC(s2twp)로 변환한 것입니다. 원어민 검수 전입니다.
